## Description
Construction d'un formulaire interactif basé sur les métadonnées de notes gérées avec obisidan.
Ces notes sont issus du jeu de données public https://www.kaggle.com/datasets/arthurchongg/imdb-top-1000-movies
Ce formulaire permet de faire un analyse rapide et d'identifier des cooccurences et dépendances entre les données.
Le fichier properties_explorer.md est applicable sur tout autre jeu de données

## Requirements
- installation de obsidian : https://obsidian.md/
- installation du plugin dataview : [https://obsidian.md/](https://community.obsidian.md/plugins/dataview)
